API

scitex-math — mathematical utilities for the SciTeX ecosystem.

Currently exposes integer-parity helpers extracted from scitex_gen:

  • to_even() — round down to the nearest even integer.

  • to_odd() — round down to the nearest odd integer.

Future arithmetic helpers (rounding, integer parity, simple numeric predicates) will live here as well, keeping scitex_gen focused on general-purpose utilities and scitex_dsp / scitex_nn focused on signal-processing and neural-network helpers respectively.

Pure-stdlib core — zero runtime dependencies.

scitex_math.to_even(n)[source]

Convert a number to the nearest even number less than or equal to itself.

Parameters:

n (int or float) – The input number to be converted.

Returns:

The nearest even number less than or equal to the input.

Return type:

int

Example

>>> to_even(5)
4
>>> to_even(6)
6
>>> to_even(3.7)
2
>>> to_even(-2.3)
-4
>>> to_even(-0.1)
-2
